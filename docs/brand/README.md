# 用户提供的帝江字标

`dijiang-provided.png` 是用户提供的原图，按字节保存，未修改。

网页使用 `public/dijiang-wordmark.svg`：SVG 直接嵌入原 PNG，通过显示窗口截取顶部 1024×519 区域，并沿“帝”字底部轮廓排除第 518 行开始的“号”字及其缩小后的抗锯齿残线。没有追踪或重画笔画。白色字形通过颜色矩阵显示为现有石墨色，黑色背景透明化，使其适配浅色标题栏。

该 SVG 是包含位图的裁切包装，不是纯矢量重绘。字形比例遵循用户原图。

两字按原图边界分开裁切，仅将“江”向右平移 26 个源图单位；在当前标题高度下新增约 2px 间距。画布宽度相应增加，字符本身不缩放。
