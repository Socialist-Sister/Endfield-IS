# v0.3.0 · 界面焕新与计算提速

本版更新配置与结果界面、下拉交互和品牌素材，并减少挂机启动轴搜索中的重复评估。保留手动配置、两步计算流程与原有计算口径。

## 界面与交互

- 统一配置、结果和关于页的等高线背景、黑白黄配色与标题布局；调整英文装饰标题，避免溢出并与操作按钮对齐。
- 已选干员卡使用与排班条件一致的深色背景和信号黄状态；保留并排技能结构，增大技能与下拉文字，恢复“已选 N/30”方框。
- 去掉干员列表顶部和右侧滚动条旁的多余留白，保持左右工作区对齐。
- 配方、材料、设施和练度下拉菜单增加开合过渡与箭头旋转，支持键盘选择和减少动效；按钮恢复整体水平移动。
- 顶部直接采用用户提供的“帝江”字形，与右侧两行标题等高、两字间增加约 2px；游戏内帝江号图标同步用于侧栏、favicon、移动收藏与导出图片。
- 移除网页及导出图片日产量指标下方的整行说明，压缩卡片高度，详细计算口径保留在关于页。

## 计算性能

- 优化挂机事件模拟内层循环，减少反复创建回调的开销。
- 仅对模拟效果完全相同的槽位复用等效启动轴评估，保留所有候选、决胜规则、30 分钟搜索粒度及最终 180 日预热 / 90 日采样。
- 同机默认全 E4 配置交替对照：统一轴平均 2.656s → 1.108s，分设施轴 9.114s → 3.184s，耗时分别下降约 58% 和 65%。这些是记录中的本机计算耗时，不代表所有设备或配置。
- 100 组随机模拟和 4 组完整搜索与优化前引擎结果一致；新增 7 项等效缓存边界回归测试。

## 验证与资料

- 80 项现有测试通过，其中含 Sites 4 项；生产构建和差异格式检查通过。
- Chromium 验证配置选择、两模式计算、菜单键盘操作、旧结果快照、分享链接、PNG 渲染与移动布局。浏览器 PNG 导出已确认生成且画布可读；自动化下载未写入用户下载目录。
- 同步中英文 README、实际界面截图、品牌素材来源说明与项目交接文档。
- 数学模型核验不代表所有绝对游戏产量已获实测确认；制造批次解释、培养不同耗时与线索基础周期仍沿用已有核验范围。Safari/iOS 仍需对应设备验收。
