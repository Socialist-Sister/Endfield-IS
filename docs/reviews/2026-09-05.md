# 2026-09-05 版本审查与优化

基线：`f5d7e71`（v0.1.3）。本轮修改纳入 v0.2.0 发布。保留 30 人名单、既定计算口径、两步流程和黑白黄视觉。

## 修复与改进

| 优先级 | 问题及影响 | 处理 |
| --- | --- | --- |
| P1 | 固定换班以第一次出现的干员对象作为所有班次的技能来源，跨设施换人后可能继续使用原设施技能 | 心情状态继续按干员 ID 保存，每个节点重新绑定该设施的技能对象；回归覆盖制造转培养 |
| P1 | 少量 E0 干员被集中在同一制造舱，忽略其他设施首次有人进驻时的基础产出 | 候选槽位评分加入首人启用设施的边际产出；3 人场景通过稳定周期模拟验证收益提升 |
| P1 | 计算完成后的延迟跳转、进度隐藏可能影响下一次计算；Worker 创建失败没有可见反馈 | 清理完成与隐藏定时器，忽略失效 Worker 消息，捕获构造、发送、通信失败，保留已成功结果 |
| P2 | 对上线时间排序后未同步班次索引 | 时间与原班次索引一起排序；空上线表返回有限的零产出 |
| P2 | Clipboard API 拒绝后没有备用路径；旧式复制未检查返回值，可能误报成功 | 尝试旧式复制并检查结果、恢复键盘焦点；完全失败时显示真实可手动复制的配置链接 |
| P2 | 分享配置中异常字段类型可能引起初始化异常 | 限制编码载荷大小，校验时间、练度和轴范围类型；保留用户明确清空的上线时间 |
| P2 | 多班次导出技能文本被截断，文字高度与设施高度缺乏统一约束 | 新增纯布局模块；先测量、换行，再计算卡片与设施行高度，保留两技能层级；导出按钮防重复触发，头像加载超时后降级 |
| P2 | 980px 附近名单列裁切，手机标题操作区紧张、指标区过高 | 自适应名单列与工具栏；手机指标双列、挂机成员按可读宽度排布；320–1920px 检查无页面、名单或标题溢出 |
| P2 | 搜索框缺少可访问名称，模式和导航未声明选中状态，计算限制只有鼠标悬停可见 | 补充名称、按压/当前步骤状态、可见输入提示与错误提示、克制的键盘焦点反馈和手机底部安全区 |
| P2 | npm 审计发现 Vite、PostCSS、nanoid、Browserslist 的可修复依赖问题 | Vite 6.4.2 → 6.4.3；兼容更新间接依赖。官方 registry 复审 0 漏洞 |

## 性能

使用 `scripts/benchmark.mjs`，全员 E4、默认制造配方、矿物培养、08:00/22:30 上线。以下为统一固定换班预热窗口前的本机单次记录，不代表所有设备的固定等待时间。

| 工作负载 | 修改前 | 优化阶段记录 | 改善 |
| --- | ---: | ---: | ---: |
| 挂机统一轴求解 | 16.55 s | 2.76 s | 约 6 倍 |
| 挂机分设施轴求解 | 52.32 s | 13.72 s | 约 3.8 倍 |
| 全员固定换班分配 + 汇总 | 49.8 ms | 66.3 ms | 数十毫秒；此模式重点为技能正确性 |
| 构建转换模块数 | 4,574 | 89 | 按需引入图标，减少无关模块扫描 |

挂机热点只累计当前固定配方的技能值，并复用每个事件的数值数组。没有减少 30 分钟搜索网格、180 日最终预热或 90 日最终采样窗口。

单独替换模拟热点时，两种挂机结果的完整汇总对象与原版本一致。额外使用固定种子的 50 组场景，对比旧模型与新模型的每设施产效、覆盖、在岗、停产和恢复值，最大差异为 0。分配评分与固定换班技能修复属于独立正确性变化，可能使旧方案改变。

## 验证范围与后续维护

- 内置浏览器因环境沙箱故障无法启动，使用独立 agent-browser 会话完成页面检查。
- agent-browser 的下载落盘命令会取消下载；使用独立 `data:text/plain` 下载探针也复现。因此本轮确认的是页面真实生成的 PNG 内容与下载事件，未把“自动落盘”计为通过。
- 当前人员分配仍是候选评分加模拟筛选，不声称穷举所有人员组合或保证全局最优。
- 发布前再次核查了公开资料和数学实现，明确仍待实测的绝对产量口径，详见 [计算核验](calculation-v0.2.0.md)；未擅自修改未经证实的游戏数值。
- 浏览器验收覆盖本机 Chromium。Safari、iOS 原生下载和不同系统字体仍需对应设备检查；极大量手动上线节点生成的超长图片尚未做跨浏览器 Canvas 极限测试。
