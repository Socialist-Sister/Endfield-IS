# 前端视觉精修 · 2026-09-05

基于 v0.2.0。用户要求加强设计感，保持目前操作模式；本轮为工作区视觉更新，未创建新版本或推送部署。

## 视觉依据

已在浏览器实际查看 [森空岛终末地百科](https://wiki.skland.com/endfield?header=0) 与 [fz.wiki](https://fz.wiki/)，捕获主页截图，并与实现对照。采用黑白分区、黄色定位线、大标题及档案式卡片层级，延续现有窄侧栏和配置/结果两步流程。

- 标题：加大中文页面标题，用黑底黄字步骤标记和淡色英文底字建立主次；配置与结果继续共用 PageHeading。
- 面板：统一顶部细线与标题高度，精确对齐左右工作台边缘，减轻灰色边框和阴影。
- 干员：放大本地头像，采用浅色卡片、窄黄选中线与明确勾选框；按用户反馈恢复两个并排技能块，保留左侧状态线和当前浅色配色。
- 结果：增强日产量数字层级，淡化设施底色，保留独立启动时间轨及多班次横向列。
- 交互：按用户反馈恢复按钮整体横向位移（主操作 4px、其他操作 2–3px），保留 0.2–0.3 秒过渡及减少动态效果设置。
